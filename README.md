## ⚙️ Hướng dẫn cài đặt
1. Clone repository về máy:
   ```bash
   git clone https://github.com/huanguyenchi/B2203543.git
   ```
2. Cài đặt **XAMPP**, chép thư mục `qlsv_php` vào `C:\xampp\htdocs\`.
3. Bật **Apache** và **MySQL** trong XAMPP Control Panel.
4. Tạo cơ sở dữ liệu trong phpMyAdmin.
5. Mở trình duyệt truy cập: `http://localhost/qlsv_php/`
